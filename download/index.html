GitHub Releases에서 최신 Windows 설치 파일을 확인하고 있습니다.

기존 EXE 설치본을 사용 중이신가요?

트레이에서 앱을 종료한 뒤 Windows 설정 → 앱에서 기존 프로그램을 제거해 주세요. 제거 창의 “사용자 설정, 게임 규칙, 캐시와 로그도 함께 삭제” 체크를 해제해야 설정을 유지할 수 있습니다. 그다음 새 MSI를 설치해 주세요. 기존 ZIP 자동 업데이트에서는 MSI로 전환되지 않습니다.

설치 방법

3단계면 끝납니다.

01

앱 다운로드

위의 MSI 다운로드 버튼을 눌러 설치 프로그램을 실행합니다. 필요한 앱 파일이 MSI에 포함되어 있습니다. 설치 완료 화면에서 프로그램을 실행하면 최초 설정을 안내합니다.

02

앱 실행

설치 완료 화면에서 앱을 실행한 뒤, 처음 한 번 채널과 확장 연결을 설정합니다. 기본 설치 위치는 C:\Program Files\CHZZK Auto Category입니다.

03

확장 연결

앱을 실행한 상태에서 Chrome 확장프로그램의 “연결 상태 새로고침”을 누릅니다. 로컬 연결 권한 요청이 나오면 허용해 주세요.

⌁

PC 안에서만 연결

확장프로그램과 앱은 127.0.0.1을 통해 같은 PC 안에서 통신합니다.

◎

Chrome 로그인 상태 사용

치지직 스튜디오에 로그인된 Chrome 세션을 이용해 카테고리 변경 요청을 처리합니다.

↻

자동 게임 감지

실행 중인 게임을 감지하고 연결된 치지직 게임 카테고리로 자동 전환합니다.

⌁

Windows 자동 실행

설치 후 Windows 로그인 시 트레이에서 자동 시작되며, GitHub Releases에 새 패치가 있으면 자동 업데이트를 진행합니다.

설치 후 연결되지 않나요?

확장프로그램에서 연결 상태를 다시 확인해 주세요.

앱을 먼저 실행한 뒤 Chrome 확장프로그램 팝업의 연결 상태 새로고침 버튼을 누르시면 됩니다.
