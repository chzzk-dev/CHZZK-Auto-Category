## 설치와 사용

[최신 릴리스](https://github.com/chzzk-dev/CHZZK-Auto-Category/releases/latest)에서 MSI를 내려받아 설치하세요. 처음 시작하기 안내에서 채널 주소와 확장 연결을 설정한 뒤 자동 변경을 시작합니다.

Chrome 확장 소스는 `extension/`, 직접 설치 링크로 접속해서 [Chrome 확장프로그램](https://chromewebstore.google.com/detail/chzzk-%EC%9E%90%EB%8F%99-%EC%B9%B4%ED%85%8C%EA%B3%A0%EB%A6%AC-%EC%97%B0%EA%B2%B0-%EC%BB%A4%EB%84%A5%ED%84%B0/jeefpiogpjbphganmnooglppcdicinoh)을 간단하게 다운로듷하세요.

기존 EXE 설치본에서 전환할 때는 사용자 설정 삭제를 해제한 상태로 기존 앱을 제거하고 MSI를 설치하세요. MSI 업데이트는 기존 설정을 보존합니다.
