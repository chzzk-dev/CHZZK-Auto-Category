> **4.12.8 — 쿠키앤크림 UI / 정식 최신 릴리스**
> 새 디자인과 로컬 검증은 [COOKIE_CREAM_REDESIGN.md](COOKIE_CREAM_REDESIGN.md)를 참고하세요.
> 앱 업데이트: 기본 3시간(최소 1시간), 카테고리 데이터: 기본 6시간(최소 1시간), 게임 감지: 기존 초 단위 주기를 유지합니다.
> 새 확장 코드(0.6.0)는 실제 manifest 버전을 전송합니다. 구형 확장도 통신을 유지하며, 버전 정보가 없으면 앱에 ‘확인할 수 없음’으로 표시합니다.

대시보드는 상태 요약 3개 → 현재 게임 → 최근 활동 순서로 정리했습니다. 기본 창은 1360×860이며 최소 1200×820까지 조절할 수 있습니다. 설정은 설명 왼쪽·토글 오른쪽 구조로 표시합니다. 공식 API는 빌드에 포함된 인증 정보로 자동 설정하며, 앱 시작 시 연결을 확인합니다.

롤 클라이언트는 새로 실행할 때마다 롤/롤토체스를 먼저 선택합니다. 대기실→게임 전환은 같은 실행으로 처리하며, 닫으면 자동 변경을 보류합니다. 게임 목록의 간편 설정에서 다시 선택할 수 있습니다.

**Steam 한국어 매칭:** 공식 설치본에 기본 연결 정보가 자동 설정됩니다. 사용자는 Steam API 키를 입력할 필요가 없습니다. 감지된 게임을 Steam에서 정확히 식별하고 한국어 이름으로 치지직을 우선 검색합니다. 선택적으로 등록한 개인 키는 Windows DPAPI로 보호하며, 매칭·조회 결과는 캐시합니다. Steam 로그인이나 Steam ID 입력은 필요하지 않습니다. 키가 없거나 Steam에서 확인하지 못한 게임은 기존 매칭을 사용합니다. 자세한 동작과 검증 범위는 [STEAM_MATCHING.md](STEAM_MATCHING.md)를 참고하세요.

## 설치와 사용

기존 EXE 설치본에서 전환할 때는 사용자 설정 삭제를 해제한 상태로 기존 앱을 제거하고 MSI를 설치하세요. MSI 업데이트는 기존 설정을 보존합니다.
